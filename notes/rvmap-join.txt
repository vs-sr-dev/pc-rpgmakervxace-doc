THE RESIDUE, BOTH WAYS

  the ids the maps use run 1 .. 8156
  the tables publish 2544 rows over 22 files

  A ROW COUNT IS NOT AN ID RANGE, and this tool refuses to
  pretend otherwise. The tables are indexed by POSITION within one
  tileset image; a map cell holds a GLOBAL id. Joining them
  requires the id->(image, position) mapping, and that mapping is
  not in this object: no file in the tree states it, and the help
  file's own tileset pages describe the editor's UI and not the
  encoding. So the honest join is by TILESET and not by TILE:

  images that have a name table     : 22 of 22
  images that do not                : 0
  RESIDUE on the stem join          : 0
